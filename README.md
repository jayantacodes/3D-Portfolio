# 🚀 Portfolio OS — Interactive 3D Developer Portfolio

An immersive macOS-inspired interactive portfolio experience built with modern frontend technologies, smooth animations, and futuristic UI systems.

🌐 Live Demo: https://jayantadev.in

---

## ✨ Features

### 🖥️ Interactive OS Experience
- macOS inspired UI/UX
- Draggable & resizable windows
- Apple-style animated dock
- Functional desktop environment

### 🌌 3D & Animation System
- Three.js powered 3D elements
- React Three Fiber integration
- Smooth Framer Motion animations
- Lenis smooth scrolling experience

### ⚡ Advanced System Controls
- Real-time CPU / RAM / Network dashboard
- Dynamic glitch intensity controls
- RGB sync modes
- CRT retro effects
- Multiple typography systems

### 🛠️ Built-in Tools
- Functional terminal interface
- Integrated music player
- Real-time widgets
- Multi-clock system
- Weather integration

### 🎨 Customization
- Dark / Light modes
- Custom cursor modes
- Dynamic wallpapers
- UI personalization system

---

## 🛠️ Tech Stack

### Frontend
- React 19

- Tailwind CSS

### Animation & 3D
- Three.js

### Tools & State Management

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/jayantacodes/3D-Portfolio.git
```

Go to project directory:

```bash
cd 3D-Portfolio
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```
